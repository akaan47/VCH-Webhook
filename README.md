🔧 Webhook Tools

Un petit outil Python en ligne de commande pour interagir rapidement avec des webhooks Discord. Il permet d’envoyer des messages, de supprimer, spammer ou renommer des webhooks.

✨ Fonctions disponibles

✅ Webhook Sender : Envoie un message personnalisé via un webhook.

🗑️ Webhook Deleter : Supprime un webhook.

🔁 Webhook Spammer : Spamme un message à répétition via un webhook.

✏️ Webhook Renamer : Modifie le nom d’un webhook.

📦 Installation

> Clone ce repo :
```
git clone https://github.com/akaan47/VCH-Webhook.git
cd VCH-Webhook
```

> Installe les dépendances nécessaires :
```
pip install -r requirements.txt
```

▶️ Utilisation

> Lance simplement le script :
```
python main.py
```

> Tu verras ce menu :
```
Webhook Tools

[0] Webhook Sender 
[1] Webhook Deleter 
[2] Webhook Spammer 
[3] Webhook Renamer
```

Suis les instructions affichées pour utiliser l’outil selon ton besoin.
